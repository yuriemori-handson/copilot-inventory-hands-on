# copilot-inventory-hands-on

GitHub Copilot を使って、仕様書から在庫管理アプリケーションを構築するハンズオンです。  
コードを一行も書かずに、Copilot の各モードを活用してアプリケーションを完成させることを体験します。

---

## ハンズオンの流れ

### 1. 仕様を確認する
`SPEC.md` を開き、今回作成するアプリケーションの仕様を確認します。

### 2. Plan モードで実装計画を作る
GitHub Copilot の **Plan モード** を使い、`SPEC.md` をもとに実装計画を作成します。

**プロンプト例:**
```
SPEC.md を読んで、このアプリの実装計画を作成してください。
フロントエンドとバックエンドの構成、使用ライブラリ、API 設計、実装ステップを含めてください。
```

### 3. Agent モードで実装する
GitHub Copilot の **Agent モード** を使い、実装計画に従ってアプリケーションを実装します。

**プロンプト例:**
```
SPEC.md と実装計画に従って、最小構成で動作する在庫管理アプリを実装してください。
バックエンドは Python（FastAPI）、フロントエンドは React + TypeScript（Vite）で構築してください。
```

### 4. Ask モードで生成されたコードを説明させる
GitHub Copilot の **Ask モード** を使い、生成されたコードの内容を確認・理解します。

**プロンプト例:**
```
このバックエンドの API 構成と各エンドポイントの役割を初心者向けに説明してください。
このフロントエンドの状態管理の実装を説明してください。
```

### 5. ユーザー向けマニュアルを作成させる
最後に、Copilot にアプリのユーザー向けマニュアルを作成させます。

**プロンプト例:**
```
このアプリのユーザー向けマニュアルを Markdown で作成してください。
起動方法、基本操作、注意点を含めてください。
```

---

## 開発環境

本リポジトリには Dev Container の設定が含まれています。  
VS Code と Docker があれば、すぐに開発環境を起動できます。

- Python 3.12
- Node.js 20
- 推奨拡張機能: GitHub Copilot, GitHub Copilot Chat
